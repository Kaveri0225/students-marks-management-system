
# students-marks-management-system

Project Overview:
The Student Marks Management System is a database-driven application built using Python, Streamlit, and SQLite. It enables users to store, manage, and view student academic records. The application automatically calculates total marks and provides a simple interface for maintaining student data.

Technologies Used:
Python,
Streamlit,
SQLite Database,
SQL Queries,

Key Features:
Student record management,
Database integration using SQLite,
Add student details and marks,
Automatic total marks calculation,
Store data permanently in database,
View all student records,
Interactive data display using Streamlit
